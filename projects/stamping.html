Manufacturing Execution

ProdControl Stamping

Production control application for stamping work orders, plan vs actual tracking, route progress visibility, and shopfloor actual input from mobile and desktop views.

Solo End-to-End Ownership Production Control WO Progress & WIP Plan vs Actual Shopfloor Input

Workflow Illustration

The stamping flow is centered on turning daily production monitoring into an operational system. Work orders, route progress, plan versus actual, operator input, NG recording, and downtime context are surfaced into one control layer so production leaders can review execution without waiting for delayed recap.

Business Problem

Stamping teams need to monitor work order progress, actual output, operation status, and exception handling in near real-time. When progress review and actual input are fragmented, leaders lose visibility over route completion, quantity gaps, and execution status per shift.

My Role & Ownership

Independently designed and built the production control UI for stamping operations, including work order list views, operation progress cards, mobile actual input flow, and dashboard-style visibility for plan versus actual and WIP execution status.

Operational Flow

  • Production leaders review active work orders by date, shift, area, line, and part filters.
  • Each work order exposes operation sequence, route progress, current status, and output plan versus actual.
  • Operators or supervisors can open the actual input form from mobile view to record quantity, notes, and production exceptions.
  • NG and downtime context can be reviewed alongside execution progress so outstanding issues are visible per operation.

Key Capabilities

  • Plan vs actual list for quick review of target, output, gap, and achievement per job.
  • WO Progress & WIP dashboard with total WO status, route progress, and operation cards.
  • Mobile-friendly actual production input modal for faster shopfloor transaction entry.
  • Filterable execution view by date range, line, shift, product, and work order status.

Tech Stack

PHP, Chart.js, MySQL, Tailwind CSS.

Current Status

Status: Internal production control MVP focused on stamping execution visibility, mobile-friendly actual input, work order progress tracking, and operational review for plan versus actual performance.
