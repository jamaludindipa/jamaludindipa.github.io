Flagship Project • Manufacturing Execution System

META - Manufacturing Execution & Traceability Application

Internal manufacturing workflow platform for work order execution, warehouse movement, quality inspection, and end-to-end traceability.

Internal MVP Manufacturing Workflow Sanitized Screenshots

Business Problem

Manufacturing execution, material movement, inspection, and traceability often live across disconnected operational steps. META was built to connect those flows in one application pattern from material readiness to finish good delivery.

My Contribution

Designed the modular UI structure, warehouse movement pattern, work-order execution flow, and traceability-oriented navigation for a more coherent manufacturing operations experience.

Key Capabilities

  • Work order visibility across production, WIP, and final inspection.
  • Reusable movement flow for request, picking, validation, and transfer.
  • Traceability path from raw material through delivery.
  • Role-based Laravel Blade UI for manufacturing modules.

Tech Stack

Laravel 11, PHP 8.3, Blade, JavaScript, Tailwind CSS, MySQL, Playwright, GitLab, Linux Server, systemd.
